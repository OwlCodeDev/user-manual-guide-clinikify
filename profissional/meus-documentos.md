# Meus documentos

Lista dos **documentos clínicos** que você emitiu — atestados, receitas,
laudos e outros — com o respectivo status de geração e assinatura.

{% include figura.html src="profissional/meus-documentos.png" alt="Meus documentos" legenda="Lista de documentos clínicos do profissional." %}

## O que você acompanha

- **Status do documento** (rascunho, emitido, assinado).
- **Status do PDF** (em geração, pronto).
- Acesso para **baixar** ou **visualizar** o PDF assinado.

## Emitir e assinar

1. Gere o documento a partir do **prontuário do paciente**.
2. O sistema **monta o PDF** (com o papel timbrado da clínica, se configurado).
3. **Assine** com o seu [certificado ICP-Brasil](meu-certificado.html).
4. O documento assinado fica disponível para download e impressão.

<div class="dica" markdown="1">
💡 A tela atualiza o status automaticamente enquanto o PDF é gerado — não
precisa recarregar.
</div>
